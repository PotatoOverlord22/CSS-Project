# Defects Found During Unit Testing

This document records defects discovered by unit tests. Tests are written to expect **correct behavior** (not current buggy behavior).

| # | Class | Method | Description | Expected | Actual |
|---|-------|--------|-------------|----------|--------|
| 1 | `EventDrivenSimulationEngine` | `handleSystemProcessRelease` | Integer overflow in periodic system process scheduling. `nextSystemProcessReleaseTime += config.systemProcessPeriod()` can overflow `int` when the simulation runs long enough or the period is large, producing a negative time value. | The engine should guard against overflow (e.g., check before adding, use `long`, or stop scheduling when time would exceed `Integer.MAX_VALUE`). | Throws `IllegalArgumentException: Event time must be non-negative` from `Event` constructor when the overflowed negative value is used. |
| 2 | `Process` | `setRemainingBurstTime` | Missing input validation on the setter allows negative remaining burst time values. A process should never have a negative remaining burst time as it represents how many time units are left in the current CPU burst. | The setter should throw `IllegalArgumentException` when a negative value is passed. | Silently accepts any negative value without validation. |
| 3 | `Processor` | `setCurrentProcess` | Missing validation when assigning a process to a processor that already has one assigned. Double-assigning without first releasing can silently "lose" the previously assigned process. Note: this invariant is currently enforced at a higher level (`EventDrivenSimulationEngine.dispatchProcessOnProcessor` checks `isFree()` before calling `setCurrentProcess`). It is debatable whether the setter itself should also guard against misuse or remain a simple POJO setter with the contract enforced by callers. | The setter should throw `IllegalStateException` when attempting to assign a non-null process to a processor that already has a non-null current process (must release first by setting to null). | Silently overwrites the previous process reference without any error. |
